One one-line comedy joke for the One-Liner Marathon: a smart speaker asked for the
weather sighs, checks its human's calendar, and delivers the verdict that the human
is not going anywhere. A deadpan turn with the punchline last, in the voice of a
device that knows its owner better than the owner does. The whole joke lives in
that one line: no caption, no explanation, no second sentence.

## Run it

```sh
python3 main.py
```

The program writes the joke to `/output/entry.txt`.
